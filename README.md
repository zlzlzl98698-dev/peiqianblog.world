## 📖 项目愿景与定位

**赔钱博客（peiqianblog.world）** 是专为跨境办公、学术科研出海、4K 海外流媒体追剧及 AI 大模型深度用户打造的**科学上网可观测性实验室**。

不同于市面上粗制滥造的内容农场或虚假跑路盘，本项目严格恪守**“真实测速打底、晚高峰见真章、完全免责透明、商业外链 100% 隔离”**的技术与运营底线，构建了覆盖 Google、Bing 以及生成式 AI（ChatGPT Search / Perplexity / Google AI Overviews）高可检索性的全景知识图谱。

## ✨ 核心特性与架构亮点

### 🌸 1. 独创“樱花校园极客”视觉体系 (Cyber Sakura)
* **动态 Canvas 樱花雨**：微开销原生 Canvas 物理粒子模拟系统，支持流畅的落瓣飘落效果与动态风力扰动。
* **极客学妹便签交互**：二次元学妹（奈奈）陪伴式避坑便签（`StickyNote.vue`），将枯燥复杂的翻墙协议转化为易懂的指引。
* **赛博网络天文台**：深色模式为主视觉基调（暗夜星空 `#121418` 搭配高饱和樱花粉 `#FF6B9D`），集成晚高峰延迟、带宽与丢包率实时监控面板。
* **默认天黑模式（Dark Mode First）**：自动初始化深色高质感模式，同时提供主题切换滑块自由切换。

### 🏛️ 2. 六大 SEO/GEO 蜂巢知识矩阵 (Topic Clusters)
项目采用 **“一级导航 → 二级专题 → 三级长尾内容”** 的立体蜂巢内链架构：
1. **🏆 42 家机场综合推荐大矩阵**（`ranking-guide.md`）：专著级（7,200+ 纯汉字，1.6万总字符）客观横评，涵盖晚高峰零丢包专线梯队、5.6 元极限平价横评与永久不限时包。
2. **🧪 42 家深度机场评测大矩阵**（`airport-brands.md`）：42 家全品牌实验室规格数据库，支持动态分类筛选与同源站群溯源。
3. **⚡ 免费节点与订阅实测大矩阵**（`free-nodes.md`）：公开节点池实测，深度剖析中间人窃密、投毒与 ChatGPT 连带封号机理。
4. **❓ 机场百科与全景 FAQ 大矩阵**（`airport-faq.md`）：汇集 100 问高频疑难杂症，从 TUN 模式原理到软路由回环排障全景收录。
5. **🚨 跑路预警与黑名单避坑矩阵**（`scam-warnings.md`）：高危跑路雷达排查、终身超低价盘商业逻辑拆解与止损预案。
6. **🎁 免费试用与一元尝鲜大矩阵**（`free-trials.md`）：0 元体验领取指南、1-2 元试水测速包与晚高峰 4K 压测标准清单。

### 📡 3. 42 家机场品牌客观评测库
* 包含 **光速云**（IEPL双专线第一主推）、**暮光加速**（BGP多端不限设备）、**飞猫云**（自研专属客户端免配置）、**微风网络**（IEPL+VLESS性价比之王）等 42 家独立评测单页。
* 归档收录 **26 张高清晚高峰测速面板图与流媒体解锁截图**，绝不凭空捏造数据。

### 💻 4. 全平台客户端从零到一教程
* 覆盖 **Windows**（Clash Verge Rev / v2rayN）、**macOS**（M 系列原生支持）、**iOS**（Shadowrocket 小火箭）、**Android**（FlClash）以及 **OpenWrt** 软路由透明网关（Fake-IP 混合模式）。

### 🛡️ 5. 爬虫级高级预防性技术 SEO / GEO
* **100% Canonical 自引用**：全站 59 个页面通过 `transformHead` 自动注入正式规范绝对 URL，彻底杜绝重复内容与权重分散。
* **立体 Schema 知识图谱**：
  * 全局声明 `WebSite` 与 `Organization`；
  * 全站内页覆盖 `BreadcrumbList` 面包屑；
  * 品牌评测页动态输出 `Review` + `Product` 结构化数据；
  * 客户端教程输出 `TechArticle`，专题矩阵输出 `Article`；
  * 44 组原生 `<details><summary>` 结构保障 AI 搜索引擎精准抓取。
* **外链连坐防范**：全站 180 处商业引流外链 100% 严密包裹 `rel="nofollow sponsored noopener"`。
* **多搜索引擎爬虫友好**：`robots.txt` 专门对 `Googlebot`、`bingbot`、`Baiduspider`、`yisouspider`（神马/夸克）显式开放。

## 🚀 快速上手与本地开发

### 环境要求
* **Node.js** >= 18.0.0
* **npm** >= 9.0.0

### 安装依赖
```bash
git clone https://github.com/zlzlzl98698-dev/peiqianblog.world.git
cd peiqianblog.world
npm install
```

### 启动本地开发热重载服务
```bash
npm run docs:dev
```
访问本地 `http://localhost:5173/` 查看实时修改效果。

### 静态生产构建 (SSG)
```bash
npm run docs:build
```
编译产物将烘焙输出至 `src/.vitepress/dist/`，耗时约 6 秒，生成 59 个纯静态 HTML、`sitemap.xml` 及静态资源。

### 本地生产环境预览
```bash
npm run docs:preview
```
将在 `http://localhost:4173/` 模拟正式生产环境下的路由与渲染。

## 🌐 静态生产部署指南 (Apache / Nginx / Cloudflare)

本站编译产物为纯静态前端文件，推荐结合自带的 `.htaccess` 部署于 **Apache** 环境，或直接托管于 **Cloudflare Pages / Vercel**：

### 1. Apache 部署
将 `src/.vitepress/dist/` 内全部文件上传至网站根目录。项目已自带高性能 `.htaccess` 规则：
* **全站 HTTPS 强制跳转**（HTTP 301 重定向）
* **规范主域重定向**（`www` 自动 301 跳转至裸域 `peiqianblog.world`）
* **Clean URLs 映射**（隐藏 `.html` 扩展名）
* **全站 Gzip / Deflate 压缩与安全响应头**（`X-Frame-Options`, `X-Content-Type-Options`）
* **静态资源强缓存**（图片/字体 1 年，HTML 1 小时保证新鲜度）

### 2. 搜索引擎上线提交清单
* **Bing Webmaster Tools**：提交 `https://peiqianblog.world/sitemap.xml`
* **Google Search Console**：提交 `https://peiqianblog.world/sitemap.xml`
* **神马站长平台 (yisouspider)**：提交 `https://peiqianblog.world/sitemap.xml`
* **百度搜索资源平台**：提交 `https://peiqianblog.world/sitemap.xml`
